## Архитектура

Проект состоит из следующих компонентов:

### Библиотека v8_reader_lib

Статическая библиотека, содержащая код для чтения файлов 1С:

- **APIcfBase** - основной класс для работы с файлами конфигураций
- **V8File** - работа с форматом файлов 1С
- **MetadataObject*** - классы для различных типов метаданных
- **zlib** - интеграция со сжатием данных

### Приложения

- **v8_reader_gui** - GUI приложение на wxWidgets
- **v8_reader_cli** - консольная утилита для пакетной обработки

## API библиотеки

### Основные классы

#### APIcfBase

Основной класс для работы с файлами конфигураций 1С.

```cpp
#include "APIcfBase.h"

// Пример использования
APIcfBase reader;
if (reader.LoadFile(L"config.cf")) {
    // Работа с конфигурацией
}
```

### Поддерживаемые типы метаданных

- Catalogs (Справочники)
- Documents (Документы)
- Registers (Регистры)
- CommonModules (Общие модули)
- и другие...

## Перенос с C++ Builder

### Проблемы совместимости

Исходный код написан на C++ Builder и использует:

1. **VCL компоненты** - требуют замены на wxWidgets
2. **AnsiString/UnicodeString** - требуют замены на std::string/std::wstring
3. **__int64** - заменить на int64_t
4. **System::DynamicArray** - заменить на std::vector

## План разработки GUI

### Основные функции

1. **Открытие файлов**
   - Поддержка drag-and-drop
   - Недавние файлы в меню
   - Прогресс бар при загрузке больших файлов

2. **Дерево метаданных**
   - Иерархическое представление
   - Иконки для разных типов объектов
   - Контекстное меню

3. **Просмотр свойств**
   - Таблица свойств объекта
   - Редактирование (в будущем)
   - Экспорт свойств

4. **Поиск**
   - По имени объекта
   - По содержимому модулей
   - Подсветка результатов
